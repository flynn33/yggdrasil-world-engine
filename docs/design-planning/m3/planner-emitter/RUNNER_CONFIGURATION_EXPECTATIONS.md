The complete PlannerEmitterBinding return, 23 business ports, 36 business wire definitions, policies, source pins, grants and capacities remain unchanged. This draft claims no implementation or runtime acceptance.

ReferenceGenerationRunner.configuration MUST accept only the additive keyword-only expectations `state_model=None` and `diagnostics=None`. Omitted expectations MUST preserve the existing original-owner/current-composition checks and exact PlannerEmitterBinding return. A supplied state_model MUST be the exact StateModel class and the original model identity retained by this original runner constructor. Supplied diagnostics MUST be the exact original ReferenceDevelopmentDiagnostics or ReferenceReleaseDiagnostics identity retained by that constructor. Copied, foreign, reflected or hostile arguments MUST refuse with the existing bounded PlannerEmitterContractError before equality, hashing, coercion, instance callbacks, locks, collector IO, computation or grants. The helper MUST inspect only its own original constructor cookie and owned members, and MUST return no caller-provided authenticity flag. [YWE-REQ-0049]

This proves the configured local composition; it MUST NOT confer capture completion, target authority or Session/Recovery publication authority. Current binding checks and actual ticket/producer/capture proofs remain independently required. Existing configuration and original result authentication MUST remain readable after shutdown for truthful late cleanup. [YWE-REQ-0049]

Required actual controls before acceptance: omitted and exact supplied originals return the same complete binding; wrong original model or collector, shallow/deep copied runner and reflected constructor replacement refuse with zero caller hooks or IO; hostile metaclass arguments invoke zero equality/hash/string hooks; the Core constructor/configuration uses both explicit expectations before admission.
