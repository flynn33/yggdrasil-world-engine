# Canonical ASH Baseline

This directory is the repository's authoritative ASH dependency source used by
YWE:

- `core/` - F2^9 state space, canonical codeword set, state or vertex identity, admissibility, diagnostics, classification, and recoverability semantics.
- `algorithms/` - XOR-by-codeword transitions, averaging, branching, recovery, containment, topology, axioms, and generation planning.
- `interfaces/` - diagnostic schema, rule taxonomy, semantic contracts, and implementation contracts.
- `registries/` - canonical ASH-owned registry contracts included in the pinned dependency identity.
- `verification/` - invariant, conformance, and acceptance requirements.

YWE treats these files as the semantic authority for the pinned ASH dependency.
The root-level `specs/` directory is the deterministic generated mirror. The
mirror is checked and regenerated by `scripts/sync_ash_specifications.py`; it
cannot override this source tree. This README is informative and is excluded
from synchronized mirror content and dependency hashing.
