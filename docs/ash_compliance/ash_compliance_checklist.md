# ASH Compliance Checklist

Use this checklist at every major milestone to verify ASH cosmological compliance.

## Realm System

- [ ] Nine canonical realms are present and unmodified
- [ ] No new realms have been created outside the canonical nine
- [ ] Realm definitions match the master specification
- [ ] Players start in the Physical Realm
- [ ] Realm travel requires attunement threshold AND thin veil location
- [ ] Players always have access to the Physical Realm

## Alignment System

- [ ] White Wolf and Dark Wolf represent informational forces, not morality
- [ ] Alignment is accumulation-only (no subtraction)
- [ ] Both alignments can increase simultaneously
- [ ] Single quests can award both wolf attunements
- [ ] Balance is treated as the healthy target state, not domination of one wolf over the other

## Pattern Generation

- [ ] All procedural content derives from ASH pattern detection
- [ ] No independent random generators for meaningful content
- [ ] Pattern strength is bounded between 0 and 1
- [ ] All expansion engines read from the ASH Pattern Engine

## Cosmology

- [ ] Divine Core is the origin center
- [ ] White Wolf and Dark Wolf emerge with Divine Core creation as paired companions of consciousness
- [ ] Wolves cannot die permanently and may only lose coherence temporarily before returning
- [ ] Creation event sequence is preserved from Dark Star through Divine Core and the nine fixed realms
- [ ] Realm and plane terminology remains normalized as one ontology category

## Perception

- [ ] The world does not change; player perception changes
- [ ] Same location can be perceived differently by different players
- [ ] Perception is driven by cosmic state (attunement, alignment, bloodline, memory)

## Narrative

- [ ] All narrative derives from ASH patterns
- [ ] Player narrative memory persists across sessions
- [ ] Consequences are irreversible once recorded
- [ ] Significant events are evaluated for myth eligibility

## Bloodlines

- [ ] Bloodlines influence cosmic eligibility, not lock destiny
- [ ] Bloodline resonance affects quest interpretation and prophecy activation
