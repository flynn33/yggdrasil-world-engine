# ASH Compliance

The Yggdrasil World Engine must never violate the ASH cosmological model.

## Compliance Rules

| Rule | Requirement |
|------|-------------|
| Realms are fixed | The nine realms cannot be created, destroyed, or modified |
| Player resonance changes | Players change attunement, not the realms themselves |
| Patterns drive generation | All procedural content originates from ASH pattern detection |
| Information states govern events | Cosmic information states determine what happens in the world |
| Divine Core is origin center | The Divine Core is the ultimate origin of all reality |
| Wolves predate realms | White Wolf and Dark Wolf exist before and outside the realm system |

## Final Compliance Principle

At every major milestone, the engine should undergo a sanity check to ensure gameplay systems do not violate:

1. Fixed realm cosmology
2. Informational-force interpretation of White/Dark Wolf
3. Pattern-driven generation rules
4. Divine Core creation model
5. Bloodline cosmological resonance

## No Independent Random Generators

All procedural systems must derive from ASH Pattern Detection. No subsystem may become an independent random generator detached from the cosmic state.

See `ash_compliance_checklist.md` for the milestone review checklist.
