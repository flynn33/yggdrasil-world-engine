# WRW:ER Campaign Identity Model

## Campaign Structure

Where Ravens Wait: Eternal Reckoning begins as a canonical continuation of Where Ravens Wait: The Blood Remembers.

The first playthrough is an authored protagonist campaign. The player controls Nathruun. The game opens after the novel, with Nathruun waking in Raven Fall beside Floki, his raven companion and ancestor, the historical Floki Hrafen Vilgerson.

After Nathruun's main story campaign is completed, custom-origin mode unlocks. Custom-origin identity is not a conventional race/class/stat creator. It is a future ASH Model / WRW universe placement resolver.

## Player Identity Modes

```text
canonical_nathruun_campaign
  -> available at game start
  -> authored protagonist mode
  -> teaches world, branch reality, companion, ability, consequence, and bloodline systems

custom_wrw_origin
  -> locked at game start
  -> unlocks after Nathruun main campaign completion
  -> resolved later through ASH Model / WRW universe placement
```

## Opening State

```text
player_identity = nathruun
opening_location = raven_fall
opening_context = after_where_ravens_wait_the_blood_remembers
persistent_raven_companion = floki_hrafen_vilgerson
```

## Custom-Origin Deferral

The custom-origin resolver is deferred. Future design must resolve:

```text
plane attunement
bloodline or non-bloodline resonance
origin pressure
branch-reality signature
ancestral or non-ancestral companion resonance
world memory before arrival
ability emergence pressure
faction / realm relevance
```

## Clean Rule

```text
The first playthrough belongs to Nathruun.
The post-campaign identity belongs to the player.
```
