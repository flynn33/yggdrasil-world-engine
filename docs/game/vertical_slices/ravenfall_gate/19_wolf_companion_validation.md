# Wolf Companion Validation — Ravenfall Gate

The wolves are physical companion presences, not abstract meters.

## Required validation

- Both wolves are represented as companion presences in the slice.
- At least one path includes quest assistance.
- At least one path includes combat or threat assistance.
- At least one path includes vision/signal presence.
- Any decoherence is temporary and recoverable.
- Permanent wolf death is forbidden.
- Morality language is absent.
