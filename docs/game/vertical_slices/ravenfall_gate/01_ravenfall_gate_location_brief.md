# Ravenfall Gate Location Brief

Status: `phase_16_recovery`

## Location summary

Ravenfall Gate is a ruined threshold market built around a broken crossing point. Merchants, witnesses, oathkeepers, scavengers, hidden keepers, and threshold-touched creatures may appear depending on branch state and player history.

## Base function

```text
Location type: threshold ruin / market / oath-site
Primary planes: Physical, Shadow, Mental, Causal
Optional pressures: Etheric, Astral, Celestial
Primary systems tested: location mutation, branch overlay, quest generation, wolf companionship, ability use, reward resolution
```

## Base truth

Ravenfall Gate exists as a physical ruin and crossing place. Its buried oath is hidden until the player discovers or triggers it.

## Branch-sensitive truth

The oath's status differs by player branch:

```text
unrevealed
publicly revealed
secretly concealed
ritually bound
studied but unresolved
weaponized as leverage
```

## Design note

Ravenfall Gate uses runtime-generated branch state. Player choice, source context, and engine consequence systems produce its branch states.
