# Ravenfall Gate Ability Use Plan

Status: `phase_16_recovery`

## Candidate abilities

```text
Oath-Sight
  Reveals hidden oath traces, contradiction patterns, and concealed relation lines.

Grave-Anchor
  Stabilizes a collapsing threshold or holds a hostile force in place.

Twin Threshold Step
  Requires coordinated wolf presence; crosses or stabilizes a partially awakened route.

Blood-Echo Hearing
  Lets the player hear ancestral memory embedded in the gate.

Causal Thread Mark
  Marks an unresolved choice so future generation keeps tracking it.
```

## Rule

Abilities are not generic skill-tree powers. They are manifestations of consequence, plane attunement, lineage/bloodline resonance, wolf companionship, branch history, artifact binding, myth/prophecy exposure, or threshold events.
