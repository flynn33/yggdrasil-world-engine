# Ravenfall Gate Combat Encounter Plan

Status: `phase_16_recovery`

## Purpose

Phase 16 needs enough combat design to prove that wolf companions and abilities can participate in combat. It does not implement the full combat engine.

## Encounter candidates

```text
Oath-Warped Shade
  A relation-fractured entity bound to the buried oath.

Threshold Raider
  A mortal or factional attacker seeking leverage over the oath.

Echo-Hound
  A creature formed from repeated oath memory and threshold pressure.

Contained Shadow Break
  A temporary anomaly if the player destabilizes the oath.
```

## Wolf combat involvement

```text
White Wolf:
  reveals weak points, protects against pattern backlash, exposes deception.

Dark Wolf:
  anchors enemies, contains Shadow pressure, endures impact, guards memory.

Both wolves:
  coordinate during bind or threshold stabilization moments.
```

## Canon rule

Wolves cannot be killed. Combat may temporarily decohere them if pressure exceeds coherence limits.
