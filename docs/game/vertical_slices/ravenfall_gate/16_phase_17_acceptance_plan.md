# Phase 17 Acceptance Plan — Ravenfall Gate

This document defines how the Ravenfall Gate vertical slice is accepted at the design level.

## Required paths

1. Reveal the Buried Oath.
2. Conceal the Buried Oath.
3. Bind the Buried Oath.
4. Study the Buried Oath.
5. Weaponize the Buried Oath.

## Acceptance focus

Each path must prove a complete trace through branch event, quest reward resolution, player state, worldstate/location consequence, wolf companion behavior, ability/combat use, content signals, and future generation bias.
