# Choice Path Validation

## Reveal

Must create public truth pressure, witness/faction/lore signals, and future public myth eligibility.

## Conceal

Must create hidden branch pressure, keeper/shadow/lore signals, and future concealed-path eligibility.

## Bind

Must create threshold stabilization pressure, twin-wolf coherence support, and future route/binding eligibility.

## Study

May avoid major mutation but must produce diagnostic no-op or interpretive consequence.

## Weaponize

Must create faction leverage, risk/consequence pressure, and future instability or retaliation eligibility.
