# Future Generation Bias Validation

Future generation bias proves that Ravenfall Gate consequences affect later generation.

## Required evidence

Every major path must produce either:

- `FutureGenerationBiasUpdate`, or
- a documented reason why the path does not yet affect future generation.

## Preferred bias categories

- future quest eligibility;
- NPC/faction reaction;
- location revisit state;
- wolf companion state;
- ability pressure;
- myth/prophecy pressure;
- artifact/creature eligibility.
