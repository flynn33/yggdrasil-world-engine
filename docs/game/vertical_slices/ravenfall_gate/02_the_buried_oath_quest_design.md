# Quest Design — The Buried Oath at Ravenfall Gate

Status: `phase_16_recovery`

## Quest premise

The player discovers that Ravenfall Gate was built over a buried oath. The oath binds old witnesses, hidden keepers, and a threshold route that has not fully awakened.

The player must decide what to do with the oath.

## Completion modes

```text
Reveal: expose the oath publicly.
Conceal: hide the oath and guard it from public knowledge.
Bind: stabilize the oath without fully revealing or burying it.
Study: interpret the oath without resolving it yet.
Weaponize: use the oath as leverage.
```

## Required systems

```text
Phase 9 branch reality
Phase 10 player runtime state
Phase 11 worldstate/location mutation
Phase 12 quest/NPC/lore generation
Phase 13 twin wolf companions
Phase 14 ability/power engine
Phase 15 quest reward resolver
```

## Quest rule

The quest is not complete when a flag is flipped. The quest is resolved when consequence packets update the player, branch, world, location, wolves, abilities, myth/prophecy pressure, and future generation bias.
