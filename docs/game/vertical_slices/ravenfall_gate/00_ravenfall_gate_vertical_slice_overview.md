# Ravenfall Gate Vertical Slice Overview

Status: `phase_16_recovery`

## Slice identity

```text
Game: Where Ravens Wait: Eternal Reckoning
Engine: Yggdrasil World Engine
Slice: Ravenfall Gate
Primary quest: The Buried Oath at Ravenfall Gate
```

## Purpose

Ravenfall Gate is the first controlled game-layer vertical slice. It validates whether YWE can support a living world that remembers player action, mutates locations, generates branch-specific consequences, and lets the twin wolves physically assist the player.

## Core experience

The player discovers a buried oath beneath a ruin-market threshold. The oath is not just lore. It is a consequence-bearing pattern that can be revealed, concealed, bound, studied, or weaponized.

Each choice affects:

```text
location phase
branch reality
worldstate deltas
wolf companion behavior
plane attunement
lineage resonance
ability pressure
NPC and faction response
lore visibility
myth seed
prophecy pressure
future generation bias
```

## Core promise

The location must feel different when revisited because the player acted.
