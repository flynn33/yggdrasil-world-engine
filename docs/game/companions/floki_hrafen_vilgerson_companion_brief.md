## Not a Generic Pet

Floki must not be implemented as a standard pet, replaceable animal companion, cosmetic familiar, or inventory summon. He is a persistent player-bound companion state with ancestral, narrative, and systemic authority.

## Death / Removal Rule

Floki is not governed by standard mortal companion death, despawn, or replacement rules. Any absence must be explicit story-state and traceable through runtime state, not a default companion removal.
