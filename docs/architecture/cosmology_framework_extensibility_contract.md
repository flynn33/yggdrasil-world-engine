# Cosmology Framework Extensibility Contract

Date: 2026-05-19
Status: canonical source-truth contract

## Purpose

Clarifies that YWE cosmology is a framework foundation, not a fixed game setting.

## Designers may define

- lore;
- mythologies;
- pantheons;
- gods;
- spirits;
- factions;
- cultures;
- civilizations;
- histories;
- world timelines;
- realm names;
- narrative skins.

## Designers may not replace

- structural ontology;
- pattern-state logic;
- consequence logic;
- perception/worldstate boundary;
- non-moral dual-variable balance logic;
- lineage resonance propagation logic;
- ASH Pattern System resilience and diagnostic role.

## Canonical distinction

The engine provides the cosmological framework.
The game provides the world.
