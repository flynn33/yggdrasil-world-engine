# Ability and Branch Reality Integration Contract

Abilities exist inside the player's active leaf branch reality. They may be available, transformed, sealed, or decohered depending on branch history.

## Branch rules

- An ability may be eligible in one branch and sealed in another.
- Branch-specific ability changes must not rewrite base ontology.
- Ability use that changes the branch must emit consequence records.
- Branch reality is not a pre-generated skill tree.
