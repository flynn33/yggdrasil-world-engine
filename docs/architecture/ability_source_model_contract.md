# Ability Source Model Contract

Every ability must identify why it exists.

## Source reference categories

```text
plane_attunement_ref
lineage_resonance_ref
wolf_companion_state_ref
leaf_branch_ref
branch_event_ref
worldstate_delta_ref
location_state_ref
quest_resolution_ref
artifact_binding_ref
myth_record_ref
prophecy_pressure_ref
celestial_identity_ref
existence_potential_ref
pattern_vector_ref
asp_diagnostic_ref
```

## Source rules

- At least one source reference is required.
- Major abilities should use multiple source references.
- Source references must be traceable.
- Wolf source references must point to companion state and/or companion events, not morality scores.
- ASH Pattern System source references should refer to diagnostic/resilience/conformance support, not topmost cosmology.
