# Lineage Resonance Model Contract

Date: 2026-05-19
Status: canonical source-truth contract

## Purpose

Defines lineage resonance as a simulation-level mechanic.

## Core statement

The engine baseline supports lineage resonance: inherited cosmological attunements propagate across generations or analogous lineage structures.

Lineage resonance can influence:

- realm attunement;
- dual-variable balance;
- mythic potential;
- prophecy eligibility;
- hidden access rules;
- perception overlays;
- generated quest pressure;
- narrative function.

## Designer extensibility

Designers may implement lineage resonance as:

- ancestry;
- bloodline;
- inheritance;
- faction legacy;
- spiritual lineage;
- school/tradition lineage;
- synthetic ancestry;
- any setting-appropriate propagation system.

## Boundary

Lineage resonance opens doors and creates pressure. It does not determine destiny.
