# Bloodline Resonance Runtime Contract

## Purpose

Bloodline Resonance tracks inherited, discovered, or awakened lineage pressure that influences branch reality, identity progression, and future generation.

It is not a static class lock.

## Runtime use

Bloodline Resonance may influence:

```text
celestial identity reveal
location access
ancestral memory fragments
quest eligibility
NPC recognition
artifact binding
myth participation
prophecy pressure
ability pressure
branch generation
```

## Resonance model

Each bloodline signal may track:

```text
bloodline_id
status
score
stability
known_publicly
revealed_to_player
source_refs
last_changed_by
```

## Status values

```text
unknown
dormant
suspected
active
awakened
unstable
integrated
```

## Public vs private truth

Bloodline may be:

```text
unknown_to_player
known_to_player
claimed_by_faction
contested_by_faction
verified_by_worldstate
mythologized
```

The system must distinguish personal reveal, faction claim, myth, and shared world truth.

## Forbidden

```text
bloodline_as_static_class_lock
bloodline_reveal_without_evidence
bloodline_mutating_base_cosmology
faction_claim_as_automatic_truth
```
