# ASH Model Engine Cosmology Contract

Date: 2026-05-19
Status: canonical source-truth contract

## Purpose

Defines the ASH Model of the Universe as the mathematical and ontological foundation for Yggdrasil World Engine.

## Core statement

Yggdrasil World Engine is built on the ASH Model of the Universe.

The engine cosmology defines the structural logic of:

- simulation;
- state;
- perception;
- pattern emergence;
- consequence;
- procedural generation;
- myth emergence;
- prophecy activation;
- lineage resonance;
- dual-variable balance.

## Framework foundation

The engine cosmology is not a fixed game setting or one required mythology.

It is a cosmological implementation framework. Designers may define their own lore, mythologies, factions, gods, cultures, histories, and worlds on top of the structural ontology.

## ASH layers

### Archetype Layer

Defines fundamental symbolic patterns that drive procedural generation. Archetypes are structural constants and describe the shape of meaning.

### Symbolic Layer

Maps archetype patterns to narrative and simulation events. It translates abstract cosmological state into player-experienceable content.

### Harmonic Layer

Ensures cosmological consistency across generated content, resolves conflicts, and maintains structural coherence.

## Default structural realm framework

The engine baseline provides nine cosmological state layers. These are simulation constants used to classify entities, events, perception, and narrative function.

They are not mandatory fictional locations at the engine layer.

Implementations may rename, reskin, and narratively reinterpret them while preserving the structural relationship model.

## Fixed vs extensible

Fixed:

- structural ontology;
- layer relationships;
- simulation consequence logic;
- pattern-state derivation;
- non-moral dual-variable balance logic;
- lineage resonance propagation logic.

Extensible:

- lore;
- names;
- pantheons;
- factions;
- cultures;
- histories;
- gods;
- spirits;
- fictional presentation of realm layers.

## Forbidden

- treating engine cosmology as a mandatory setting bible;
- treating one game's lore as required for all YWE implementations;
- generating meaningful content outside the cosmological state model;
- replacing the ASH Model with local feature-engine rules;
- treating ASH Pattern System as the topmost cosmological authority.
