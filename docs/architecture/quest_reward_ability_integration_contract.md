# Quest Reward Ability Integration Contract

Quest rewards may create, increase, stabilize, transform, seal, or decohere
ability pressure.

## Ability reward effects

```text
ability_unlock_pressure_delta
ability_availability_delta
ability_state_update
AbilityUnlockPressure
ability_source_ref_update
source_refs
ability_risk_profile_update
ability_decoherence_update
ability_recovery_update
```

## Rules

```text
Abilities are not generic skill-tree rewards.
Ability reward effects require source provenance.
Ability rewards may be used in combat, quests, exploration, perception,
social resolution, recovery/containment, and threshold traversal.
```
