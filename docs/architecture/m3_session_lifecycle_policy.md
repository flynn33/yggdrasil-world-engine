# M3 reference session lifecycle safety policy

Policy identity: YWE-SESSION-SAFETY-001
Policy version: 1.0.0
Status: active N3 safety policy, adopted October 11, 2026 before dependent implementation. Implementation and runtime verification remain outstanding.
Owner and partition: ywe_core.
Requirement: [YWE-REQ-0044]. Decision: ADR-0033.
Direction: YWE-DIRECTION-20261009-AUTONOMOUS-N3.
Preparation source: 0949184b7f1be0960fec9dd409cbf09647921e61.
No historical external review or approval is asserted.

1. RecoveryEngine remains the single public recovery and lifecycle authority. Its exact per-engine ReferenceSessionLifecycle collaborator owns reference lifecycle execution and serialized state, using a private per-engine identity capability and one session. ReferenceSession delegates read, execute and history to that engine. The collaborator is a narrow implementation within RecoveryEngine's semantic ownership; it is not another public recovery authority or a global registry. Standalone immutable N2 recover remains available with no lifecycle owner or execution gate.

2. Admission and effects require the exact current complete N3_LIFECYCLE canonical vector, the exactly paired seven-pin RecoverySourceBinding, the full current profile binding and this local policy binding. The actual guard is state_values.canonical_source_baseline(binding), not aggregate-only comparison. Constructor recognition is not host source verification, authority authentication or native qualification. Initial context must be neither contained nor halted. An observed FAILED classification remains running in NORMAL mode until a deliberate authorized halt. A structurally valid semantic session is created with AUDIT_BLOCKED when Diagnostics registration fails, so failed observation cannot prevent a later required halt. Invalid structural source/profile/origin data never grants a session.

3. Each snapshot exposes current_assessment_reference and observed_system_state_class. They are populated only by an actual complete StateModel assessment associated by the owner with that exact current generation, state and actual context. State equality after a state cycle cannot restore membership. Full expected-snapshot equality is checked before admission. The privately issued lease retains both the before snapshot and the distinct active snapshot; subsequent checks use the owner's exact current lease phase snapshot. Copying a lease, request or wire record does not copy issuance authority.

4. An admitted recovery uses a fresh actual StateModel child assessment and independent Detection/Classification root. The caller supplies the exact current live origin, but its RecoveryOperationContext and propagation/external-authority observations are already bound to the deterministic fresh child reference request_reference + ':origin:assessment'. RecoveryEngine invokes its existing post_facts_provider with the accepted live origin, requested fresh DiagnosticContext and actual current state/context. It requires newly bound predicate evidence and performs actual StateModel assessment and once-only Diagnostics completion. It never copies or silently rebinds old predicates. The N1 origin scope completes before N2 admission. N2 finishes once before lifecycle admission. A matching COMPLETE result, exact full current bindings and actual STABLE/VALID candidate assessment are required before recovery publication.

5. Propagation SAFE is required before ordinary correction, normalization or fallback effects. RISK requests canonical PROPAGATION_RISK containment. UNAVAILABLE requests policy containment under OPERATOR_REQUEST with the recognized policy authority and preserves the actual unavailable observation. No false safety, mathematical no-path, authenticated supervisor, human participation or physical propagation is inferred. Containment permits only read-session, read-diagnostics, paired export, authorized resolution and halt. Recovery and ordinary publication are forbidden. These are the declared reference operations, not a claim about a native runtime.

6. Operator intervention and policy-driven containment exit are explicit authorized target-replacement operations. They require exact current containment identity and full snapshot, an AUTHORIZED OPERATOR or POLICY observation matching the route, SAFE propagation and SATISFIED CONTAINMENT_CLEAR boundary evidence. StateModel supplies a fresh pure target proof under full current bindings and explicitly prospective SystemContext(false,false), requiring VALID and expected STABLE/NO_ACTION. This does not claim that the still-contained owner already has NORMAL context. The lifecycle owner rechecks the lease, all bindings, authority and boundary evidence and atomically assigns the target and clears containment. Actual post-mode StateModel assessment follows under the newly observed NORMAL context. Actual CONTAINED assessment similarly follows containment entry. Neither path copies predicate evidence: these contexts consult no predicates, so newly bound NotEvaluatedPredicate records explicitly state that no predicate was consulted. Ordinary admission stays AUDIT_BLOCKED until the actual assessment and once completion are confirmed. Postcommit failure preserves the committed truth and blocks later ordinary effects.

7. A halt trigger must be warranted by actual bound evidence. CONTAINMENT_BREACH requires a SATISFIED breach observation and actual contained mode; a resolution route name is insufficient. OPERATOR_HALT_REQUEST requires an authorized operator observation. POLICY_HALT_REQUEST requires an authorized policy observation or an actual owner policy decision. ESCALATION_FROM_FAILED requires an actual FAILED/no-path assessment and external halt direction or actual UNREACHABLE authority evidence; UNAVAILABLE is not UNREACHABLE. UNRESOLVABLE_BLOCKED_RECOVERY requires actual RECOVERY_NO_PATH and CONTAINMENT_UNAVAILABLE boundary observations. Prior N2 references resolve only to actual owner-retained results. No caller-supplied N2 packet is accepted as a certificate.

8. A valid mandatory first halt atomically latches SAFE_HALT, consumes the reserved terminal generation if needed, revokes following grants and seals main-chain membership in memory before any clock, reservation, collector, store, health or retention callback. Failure of those callbacks cannot leave the owner writable. No uncontrolled callback runs under the lifecycle lock. A private per-command SessionExecutionGate grants each following N2 collaborator, candidate computation and capture stage under that lock, then invokes it outside. Halt revokes future grants. Already granted work is not physically preempted. Its late result and actual storage/completion observations remain separate correlated audit evidence and cannot publish or become frozen main-chain successors.

9. Session-owned collector operations recheck gates after clock/store callbacks. Terminal, denial, freeze and final retention ports use nonblocking collector acquisition and reject reentrant external-callback IO rather than waiting on a callback that may be waiting for halt. A busy port returns truthful NOT_CONFIRMED. Existing admitted N2 scopes still finish exactly once through a late-audit cleanup lane; cleanup releases resources and retains the actual completion response, but grants no new ordinary work or frozen successor. Unknown external storage remains unknown. Collector-owned trusted code does not invoke lifecycle execution callbacks. Injected clock/store callbacks may reenter the owner while the existing collector IO lock is held; the terminal nonblocking/IO-depth refusal explicitly supports that path. Its capture_disposition check reads a trusted immutable phase/seal token under an independent tiny nonblocking token lock; it takes no lifecycle lock and issues no stage grant.

10. The TEN envelope and canonical stage/parent rules remain unchanged. N3 main decision bridges are existing nine-field RecoveryDiagnostic values with steps=(), describing an actual owner handoff or publication and retaining the historical original diagnosis. N2 ESCALATION never parents another CONTAINMENT/ESCALATION. A direct NORMAL halt uses an actual RECOVERY bridge before TERMINAL; a contained halt follows the confirmed CONTAINMENT predecessor. A successful resolution preserves the old chain, emits a typed ACTION_OBSERVED control with no invented TEN envelope, and establishes a new actual Detection/Classification root linked outside TEN by typed resolution metadata. Each phase and child chain remains source-valid. External/policy intervention explains the new NORMAL episode; no Recovery-after-Escalation regression is invented.

11. Business construction is not capture confirmation. Containment and safe-halt payloads retain the exact source-owned nine/eight fields and exact trigger rule. Canonical time is an actual ClockObservation with a nonnull measured monotonic value; unavailable UTC stays explicit. Missing time, original diagnosis, causal parent or full canonical closure produces PendingLifecycleRecord, never a fabricated canonical payload. A terminal closure carries the optional current zero-step bridge, the exact final halt envelope/reference and actual terminal publication without recursively embedding the current halt payload. The local twenty-one-entry grouped full-chain ceiling is not a flattened canonical TEN count. Missing source-required diagnostics remain explicit incomplete coverage, not a full conformance claim.

12. Supporting safe nodes commit before a referring acknowledgment. Lifecycle finish and N2 finish are distinct once-only calls. Matching COMPLETE confirms only that actual scope. Wrong-reference and unknown responses remain unconfirmed. Final result and denial finish responses are retained through a separate once-final sidecar with a distinct immutable reference, not by rewriting tentative evidence or recursively confirming the sidecar's own retention receipt. Actual confirmed, attempted and pending prefixes remain distinguishable.

13. Local limits are one session per owner; two recovery episodes; sixteen mode/resolution commands including one reserved final halt slot; fifteen nonterminal mode attempts; eighteen ordinary command entries; two lifecycle records per command; sixteen post-mode assessment pairs as a conservative bound; and sixteen individually retained terminal denials. Further requests consume no new arbitrary aliases, body projections or ledger entries and fold into bounded health counters with explicit overflow. Invalid preterminal objects raise SessionContractError without arbitrary repr, equality, to_record or exception-text capture. Terminal refusal occurs before caller-body parsing or replay lookup. A source-required containment handoff that cannot reserve must block ordinary admission and may invoke an actual POLICY_HALT_REQUEST under this policy; resource failure is not itself a breach/no-path proof. Actual existing, pinned and reserved global collector capacity remains authoritative. No automatic purge, unpin, reset or capacity increase forces an operation through.

14. Raw business serialization uses bounded compact ensure_ascii JSON and a 33,554,432-byte aggregate limit. Before ordinary publication, the owner checks the candidate result, prospective complete history and anticipated terminal closure. Overflow refuses SESSION_RAW_BUSINESS_LIMIT before ordinary CAS, with a compact SessionRawBusinessFailure descriptor. Mandatory halt latches first even on overflow, preserves complete immutable API object-DAG truth and reports PARTIAL or API_ONLY coverage and a pending canonical record. An oversize DAG is not called a valid raw packet; no full_diagnostic_chain is silently truncated. SessionHistory.to_record refuses rather than shortening the history.

15. State/mode publication generation uses checked unsigned64 arithmetic. Ordinary commits stop before UINT64_MAX, leaving the last value for a first halt, and never wrap. Admission and release snapshots have distinct identities without pretending to be state/mode publication. Exact repeated valid requests replay retained truth together with the current snapshot and no repeated effects. Conflicting duplicates and in-progress requests are refused. Mode and terminal gates precede replay. This is an in-process reference capability boundary; it does not protect against privileged Python reflection, same-user native interference or physical power loss.

This proposal does not satisfy all M3 exit criteria, activate M4, qualify a native product, change canonical mathematics, weaken N1/N2 fixture witnesses or assert missing historical review.
