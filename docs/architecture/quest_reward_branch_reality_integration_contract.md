# Quest Reward Branch Reality Integration Contract

Quest rewards may alter the player's leaf branch reality.

## Branch effects

```text
branch_phase_change
branch_pressure_change
branch_visibility_change
branch_access_change
branch_convergence_pressure
branch_divergence_pressure
future_generation_bias_update
```

## Rule

Quest rewards must not imply pre-generated branch trees. Branch updates are
runtime consequence states derived from the player's actual choices and current
context.
