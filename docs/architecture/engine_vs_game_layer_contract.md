# Engine vs Game Layer Contract

Date: 2026-05-19
Status: canonical source-truth contract

## Layer definitions

```text
Yggdrasil World Engine
  = agnostic engine framework

Where Ravens Wait: Eternal Reckoning
  = game / narrative layer
```

## Engine responsibilities

YWE provides:

- structural cosmology;
- procedural generation framework;
- state and consequence systems;
- perception systems;
- myth emergence support;
- prophecy activation support;
- dual-variable balance support;
- lineage resonance support;
- module contracts;
- pattern integrity / resilience through ASH Pattern System component.

## Game responsibilities

Where Ravens Wait: Eternal Reckoning provides:

- specific lore;
- specific mythic narrative;
- specific world presentation;
- specific names and cultures;
- specific wolf expression;
- specific bloodline stories;
- specific locations such as Ravenfall Gate;
- specific player-facing narrative arcs.

## Rule

The game may implement the engine cosmology in a specific mythology, but it must not redefine the engine's structural ontology.

The engine may provide structural laws, but it must not force every game to use WRW's exact lore presentation.
