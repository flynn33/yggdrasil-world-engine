# Plane Attunement Runtime Contract

## Purpose

Plane Attunement tracks the player's dynamic resonance with the nine planes of existence.

The nine planes are the base world ontology. Plane attunement is not a fixed player class. It is a runtime pressure signal used by future generation systems.

## Planes

```text
P1_Physical
P2_Etheric
P3_Astral
P4_Mental
P5_Causal
P6_Celestial
P7_Shadow
P8_Void
P9_Divine_Core
```

## Runtime use

Plane Attunement may influence:

```text
branch generation
location overlays
quest eligibility
NPC role selection
lore visibility
artifact binding
creature pressure
myth eligibility
prophecy pressure
ability unlock pressure
perception overlays
```

## Attunement model

Each plane may track:

```text
score
pressure_state
trend
last_changed_by
source_refs
```

## Pressure states

```text
dormant
latent
rising
dominant
unstable
integrated
```

## Forbidden

```text
fixed_plane_class
plane_attunement_without_provenance
plane_score_as_simple_level
plane_attunement_mutating_base_ontology
```
