# Quest Reward Truth Scope Contract

Quest rewards must classify what kind of truth changed.

## Truth scopes

```text
base_world_truth
shared_world_truth
leaf_branch_truth
player_perception
mythic_interpretation
prophetic_pressure
faction_claim
host_materialization
diagnostic_noop
```

## Rules

```text
Perception changes do not automatically rewrite shared world truth.
Mythic interpretation does not rewrite history without delta evidence.
Prophetic pressure does not guarantee a scripted future.
Faction claims are not automatically truth.
Host materialization is presentation, not source authority.
```
