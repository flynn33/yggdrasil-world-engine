# Dual-Variable Alignment Model Contract

Date: 2026-05-19
Status: canonical source-truth contract

## Purpose

Defines the engine baseline dual-variable alignment model.

## Core statement

The Yggdrasil World Engine supports a paired dual-variable alignment model of complementary simulation variables.

This is not a morality system.

Both variables can grow through the same event.

## Designer extensibility

Designers may map the variables to setting-appropriate themes such as:

- light / dark;
- order / chaos;
- creation / entropy;
- revelation / concealment;
- expansion / containment;
- any analogous paired system.

The thematic skin may change. The structural logic must remain:

```text
paired complementary variables
non-moral
balance-driven consequences
both variables may grow from same event
```

## Where Ravens Wait implementation

Where Ravens Wait expresses the model through the White Wolf and Dark Wolf.

This expression must preserve non-morality and embodied companion canon.
