# Content Generation Acceptance Contract

## Acceptance Principle

Generated Phase 12 content is accepted only if it is cosmologically grounded, context-aware, truth-scoped, and provenance-bearing.

## Accept If

```text
has branch context
has player context
has location/worldstate context
has axiom pressure or consequence pressure
has existence potential classification
has pattern vector reference
has truth scope
has rejection policy
has downstream exchange target
```

## Reject If

```text
generic random filler
no provenance
no truth scope
no location/branch/player context
lore without pattern trace
NPC without relation context
conscious NPC without self-reference classification
quest without expected consequence class
```
