# Base World Ontology Contract

## Purpose

This contract defines the base world ontology for Yggdrasil World Engine.

The base world is the stable nine-plane existence stack. It is not a generated branch, not a quest space, and not a random content layer.

## Authority

```text
Authority source: ASH Cosmological Model
Engine: Yggdrasil World Engine
Game/narrative layer: Where Ravens Wait: Eternal Reckoning
Stability component: ASH Pattern System component
```

## Nine planes

```text
P1 Physical
P2 Etheric
P3 Astral
P4 Mental
P5 Causal
P6 Celestial
P7 Shadow
P8 Void
P9 Divine Core
```

## Base world rule

The nine planes define the canonical substrate through which all generated player branch realities are interpreted.

Player choices may create leaf branch realities within or across this substrate, but they do not erase, replace, or redefine the nine-plane ontology.

## Required interpretation boundaries

```text
Physical: embodied action and concrete consequence
Etheric: vitality, subtle field, presence
Astral: dream, image, archetype, vision
Mental: thought, belief, identity, self-model
Causal: consequence, oath, fate, narrative chain
Celestial: coherence, completed pattern, higher-self attractor
Shadow: containment of unintegrated conflict; buffer before Void
Void: unstructured information and unpatterned collapse pressure
Divine Core: architectural source and rule-set center
```

## Forbidden interpretations

```text
treating planes as arbitrary biomes
deleting or replacing a plane through gameplay
treating Void as ordinary empty space
treating Shadow as simple evil
treating Celestial as simple reward space
treating Divine Core as player-authored content
generating branch reality without reference to base ontology
```

## Relationship to leaf branches

A leaf branch reality must reference the base world ontology and may express different plane pressures, overlays, access rules, location mutations, quests, NPCs, lore, artifacts, myths, or prophecies.

The branch is player-specific and runtime-generated. The base ontology remains stable.
