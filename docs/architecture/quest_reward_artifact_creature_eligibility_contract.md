# Quest Reward Artifact and Creature Eligibility Contract

Quest rewards may change which artifacts or creatures are eligible to manifest.

## Artifact effects

```text
artifact_binding_eligibility
artifact_awaken_pressure
artifact_decay_pressure
artifact_lore_visibility
artifact_threshold_use
```

## Creature effects

```text
creature_manifestation_eligibility
creature_ecology_pressure
creature_encounter_risk
creature_noncombat_resolution_path
```

## Rule

Eligibility is not the same as immediate materialization. Feature engines must
still validate and manifest content through their own contracts.
