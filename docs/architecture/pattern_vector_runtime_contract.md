# Pattern Vector Runtime Contract

## Purpose

Pattern vectors provide compact runtime descriptors for player, NPCs, creatures, artifacts, locations, myths, prophecies, and branch realities.

## Required components

```text
H_entropy
K_algorithmic_complexity
D_fractal_dimension
S_symmetry_index
L_generator_length
```

## Component meanings

```text
H_entropy:
  instability, disorder, Void pressure, collapse risk

K_algorithmic_complexity:
  layered identity, depth, difficulty of simple description

D_fractal_dimension:
  branching influence, multi-scale recurrence, lore richness

S_symmetry_index:
  coherence, balance, Celestial stability, harmonic structure

L_generator_length:
  compactness or complexity of the rule that generates the entity
```

## Runtime uses

Pattern vectors may influence:

```text
existence potential
quest pressure
NPC validity
lore eligibility
location stability
artifact binding
creature manifestation
mythic eligibility
prophecy pressure
wolf resonance interpretation
branch stability
```

## Forbidden uses

```text
using pattern vectors as morality scores
using a single component as total identity
using pattern vectors without cosmological context
replacing narrative consequence with purely numeric optimization
```
