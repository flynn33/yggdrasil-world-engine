# Runtime Cosmology Foundation Contract

## Purpose

This contract defines the runtime foundation that links the ASH Cosmological Model to YWE game-engine systems.

## Runtime foundation layers

```text
Base World Ontology
  -> stable nine-plane substrate

Branch Event
  -> meaningful player choice with consequence

Leaf Branch Reality
  -> player-specific runtime-generated reality

Existential Gameplay Kernel
  -> axiom, Φ, pattern-vector, and plane-pressure evaluation

ASH Pattern System Component
  -> diagnostics, resilience, recovery, containment, conformance, update stability

YWE Feature Engines
  -> quests, NPCs, lore, locations, artifacts, creatures, myths, prophecies, abilities
```

## Required runtime flow

```text
1. Player acts.
2. Engine classifies whether the action is a BranchEvent.
3. BranchEvent creates or mutates a LeafBranchReality.
4. BranchGenerationContext gathers player/world/location/cosmology state.
5. Existential Gameplay Kernel evaluates axioms, Φ, pattern vectors, and plane pressure.
6. ASH Pattern System component supplies diagnostics and stability/conformance checks.
7. Feature engines consume the resolved branch context.
8. Worldstate deltas and future generation bias persist consequences.
```

## Phase 9 boundary

This contract defines foundation only. It does not implement the feature engines.
