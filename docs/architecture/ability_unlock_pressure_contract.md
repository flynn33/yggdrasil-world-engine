# Ability Unlock Pressure Contract

Ability unlock pressure is the accumulated systemic pressure that makes an ability latent, eligible, unstable, unlocked, or transformed.

## Pressure sources

```text
plane_attunement
lineage_or_bloodline_resonance
wolf_companion_state
branch_history
worldstate_delta
location_threshold_event
quest_resolution
artifact_binding
myth_participation
prophecy_exposure
celestial_identity_progression
existence_potential_shift
pattern_vector_shift
```

## No generic leveling

Unlock pressure may include progression history, but it must not be reduced to:

```text
XP total
class level
currency spend
skill point purchase
```

## Pressure outcomes

```text
latent -> pressured -> eligible -> unlocked
pressured -> unstable -> coherent
unlocked -> mastered
coherent -> transformed
overstrain -> decohered or sealed
```
