# M3 current-source reference session lifecycle safety policy

Policy identity: YWE-SESSION-SAFETY-001
Policy version: 1.1.0
Owner and partition: ywe_core.
Exact policy source path: docs/architecture/m3_module_session_lifecycle_policy.md.
Compatibility owner: immutable historical policy version 1.0.0 remains authoritative for N3_LIFECYCLE. This version is authoritative only for the individually pinned M3_MODULES and M3_GENERATION full source/policy pairs.
Requirement: [YWE-REQ-0050]. Decision: ADR-0042.

1. RecoveryEngine remains the single public recovery and lifecycle authority. Its exact per-engine ReferenceSessionLifecycle collaborator owns reference lifecycle execution and serialized state, using a private per-engine identity capability and one session. ReferenceSession delegates read, execute and history to that engine. The collaborator is a narrow implementation within RecoveryEngine's semantic ownership; it is not another public recovery authority or a global registry. Standalone immutable N2 recover remains available with no lifecycle owner or execution gate. [YWE-REQ-0050]

2. Admission and effects require one exact complete source/policy pair: N3_LIFECYCLE with immutable version 1.0.0 at docs/architecture/m3_session_lifecycle_policy.md (SHA256 24e2584279b95b8e3659bd61e6b5149311f344b03b981e88f74ae37775591910), or the individually pinned M3_MODULES or M3_GENERATION vector with this version 1.1.0 at docs/architecture/m3_module_session_lifecycle_policy.md. The matching nine-field canonical vector, exactly paired seven-pin RecoverySourceBinding and full current profile are mandatory. The actual guard is complete state_values.canonical_source_baseline recognition plus the complete policy tuple; crosspairs and LEGACY_C78 grant no lifecycle session. The version 1.0.0 policy and historical vector remain unchanged; this new document does not retroactively govern that pair. Constructor recognition is not host source verification, authority authentication or native qualification. Initial context must be neither contained nor halted. An observed FAILED classification remains running in NORMAL mode until a deliberate authorized halt. A structurally valid semantic session is created with AUDIT_BLOCKED when Diagnostics registration fails, so failed observation cannot prevent a later required halt. Invalid structural source/profile/origin data never grants a session. [YWE-REQ-0050]

3. Each snapshot exposes current_assessment_reference and observed_system_state_class. They are populated only by an actual complete StateModel assessment associated by the owner with that exact current generation, state and actual context. State equality after a state cycle cannot restore membership. Full expected-snapshot equality is checked before admission. The privately issued lease retains both the before snapshot and the distinct active snapshot; subsequent checks use the owner's exact current lease phase snapshot. Copying a lease, request or wire record does not copy issuance authority. [YWE-REQ-0050]

4. An admitted recovery uses a fresh actual StateModel child assessment and independent Detection/Classification root. The caller supplies the exact current live origin, but its RecoveryOperationContext and propagation/external-authority observations are already bound to the deterministic fresh child reference request_reference + ':origin:assessment'. RecoveryEngine invokes its existing post_facts_provider with the accepted live origin, requested fresh DiagnosticContext and actual current state/context. It requires newly bound predicate evidence and performs actual StateModel assessment and once-only Diagnostics completion. It never copies or silently rebinds old predicates. The N1 origin scope completes before N2 admission. N2 finishes once before lifecycle admission. A matching COMPLETE result, exact full current bindings and actual STABLE/VALID candidate assessment are required before recovery publication. [YWE-REQ-0050]

5. Propagation SAFE is required before ordinary correction, normalization or fallback effects. RISK requests canonical PROPAGATION_RISK containment. UNAVAILABLE requests policy containment under OPERATOR_REQUEST with the recognized policy authority and preserves the actual unavailable observation. No false safety, mathematical no-path, authenticated supervisor, human participation or physical propagation is inferred. Containment permits only read-session, read-diagnostics, paired export, authorized resolution and halt. Recovery and ordinary publication are forbidden. These are the declared reference operations, not a claim about a native runtime. [YWE-REQ-0050]

6. Operator intervention and policy-driven containment exit are explicit authorized target-replacement operations. They require exact current containment identity and full snapshot, an AUTHORIZED OPERATOR or POLICY observation matching the route, SAFE propagation and SATISFIED CONTAINMENT_CLEAR boundary evidence. StateModel supplies a fresh pure target proof under full current bindings and explicitly prospective SystemContext(false,false), requiring VALID and expected STABLE/NO_ACTION. This does not claim that the still-contained owner already has NORMAL context. The lifecycle owner rechecks the lease, all bindings, authority and boundary evidence and atomically assigns the target and clears containment. Actual post-mode StateModel assessment follows under the newly observed NORMAL context. Actual CONTAINED assessment similarly follows containment entry. Neither path copies predicate evidence: these contexts consult no predicates, so newly bound NotEvaluatedPredicate records explicitly state that no predicate was consulted. Ordinary admission stays AUDIT_BLOCKED until the actual assessment and once completion are confirmed. Postcommit failure preserves the committed truth and blocks later ordinary effects. [YWE-REQ-0050]

7. A halt trigger must be warranted by actual bound evidence. CONTAINMENT_BREACH requires a SATISFIED breach observation and actual contained mode; a resolution route name is insufficient. OPERATOR_HALT_REQUEST requires an authorized operator observation. POLICY_HALT_REQUEST requires an authorized policy observation or an actual owner policy decision. ESCALATION_FROM_FAILED requires an actual FAILED/no-path assessment and external halt direction or actual UNREACHABLE authority evidence; UNAVAILABLE is not UNREACHABLE. UNRESOLVABLE_BLOCKED_RECOVERY requires actual RECOVERY_NO_PATH and CONTAINMENT_UNAVAILABLE boundary observations. Prior N2 references resolve only to actual owner-retained results. No caller-supplied N2 packet is accepted as a certificate. [YWE-REQ-0050]

8. A valid mandatory first halt atomically latches SAFE_HALT, consumes the reserved terminal generation if needed, revokes following grants and seals main-chain membership in memory before any clock, reservation, collector, store, health or retention callback. Failure of those callbacks cannot leave the owner writable. No uncontrolled callback runs under the lifecycle lock. A private per-command SessionExecutionGate grants each following N2 collaborator, candidate computation and capture stage under that lock, then invokes it outside. Halt revokes future grants. Already granted work is not physically preempted. Its late result and actual storage/completion observations remain separate correlated audit evidence and cannot publish or become frozen main-chain successors. [YWE-REQ-0050]

9. Session-owned collector operations recheck gates after clock/store callbacks. Terminal, denial, freeze and final retention ports use nonblocking collector acquisition and reject reentrant external-callback IO rather than waiting on a callback that may be waiting for halt. A busy port returns truthful NOT_CONFIRMED. Existing admitted N2 scopes still finish exactly once through a late-audit cleanup lane; cleanup releases resources and retains the actual completion response, but grants no new ordinary work or frozen successor. Unknown external storage remains unknown. Collector-owned trusted code does not invoke lifecycle execution callbacks. Injected clock/store callbacks may reenter the owner while the existing collector IO lock is held; the terminal nonblocking/IO-depth refusal explicitly supports that path. Its capture_disposition check reads a trusted immutable phase/seal token under an independent tiny nonblocking token lock; it takes no lifecycle lock and issues no stage grant. [YWE-REQ-0050]

10. The TEN envelope and canonical stage/parent rules remain unchanged. N3 main decision bridges are existing nine-field RecoveryDiagnostic values with steps=(), describing an actual owner handoff or publication and retaining the historical original diagnosis. N2 ESCALATION never parents another CONTAINMENT/ESCALATION. A direct NORMAL halt uses an actual RECOVERY bridge before TERMINAL; a contained halt follows the confirmed CONTAINMENT predecessor. A successful resolution preserves the old chain, emits a typed ACTION_OBSERVED control with no invented TEN envelope, and establishes a new actual Detection/Classification root linked outside TEN by typed resolution metadata. Each phase and child chain remains source-valid. External/policy intervention explains the new NORMAL episode; no Recovery-after-Escalation regression is invented. [YWE-REQ-0050]

13. Local limits are one session per owner; two recovery episodes; sixteen mode/resolution commands including one reserved final halt slot; fifteen nonterminal mode attempts; eighteen ordinary command entries; two lifecycle records per command; sixteen post-mode assessment pairs as a conservative bound; and sixteen individually retained terminal denials. Further requests consume no new arbitrary aliases, body projections or ledger entries and fold into bounded health counters with explicit overflow. Invalid preterminal objects raise SessionContractError without arbitrary repr, equality, to_record or exception-text capture. Terminal refusal occurs before caller-body parsing or replay lookup. A source-required containment handoff that cannot reserve must block ordinary admission and may invoke an actual POLICY_HALT_REQUEST under this policy; resource failure is not itself a breach/no-path proof. Actual existing, pinned and reserved global collector capacity remains authoritative. No automatic purge, unpin, reset or capacity increase forces an operation through. [YWE-REQ-0050]

14. Raw business serialization uses bounded compact ensure_ascii JSON and a 33,554,432-byte aggregate limit. Before ordinary publication, the owner checks the candidate result, prospective complete history and anticipated terminal closure. Overflow refuses SESSION_RAW_BUSINESS_LIMIT before ordinary CAS, with a compact SessionRawBusinessFailure descriptor. Mandatory halt latches first even on overflow, preserves complete immutable API object-DAG truth and reports PARTIAL or API_ONLY coverage and a pending canonical record. An oversize DAG is not called a valid raw packet; no full_diagnostic_chain is silently truncated. SessionHistory.to_record refuses rather than shortening the history. [YWE-REQ-0050]

15. State/mode publication generation uses checked unsigned64 arithmetic. Ordinary commits stop before UINT64_MAX, leaving the last value for a first halt, and never wrap. Admission and release snapshots have distinct identities without pretending to be state/mode publication. Exact repeated valid requests replay retained truth together with the current snapshot and no repeated effects. Conflicting duplicates and in-progress requests are refused. Mode and terminal gates precede replay. This is an in-process reference capability boundary; it does not protect against privileged Python reflection, same-user native interference or physical power loss. [YWE-REQ-0050]
