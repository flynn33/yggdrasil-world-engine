# Ability Combat and Quest Use Contract

Abilities are not only combat powers and not only quest tools.

Each major ability should define possible use in at least two of:

```text
combat
quest
exploration
perception
social
recovery_or_containment
```

## Combat usage examples

```text
protect_player
interrupt_attack
reveal_enemy_pattern
anchor_hostile_force
contain_anomaly
stabilize_decoherence
harmonic_strike
threshold_step
```

## Quest usage examples

```text
reveal_oath_trace
hear_lineage_echo
read_causal_thread
stabilize_threshold
open_or_close_branch_path
protect_witness
contain_erasure_pressure
bind_memory_to_location
```
