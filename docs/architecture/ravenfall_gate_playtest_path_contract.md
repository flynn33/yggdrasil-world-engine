# Ravenfall Gate Playtest Path Contract

Each Ravenfall Gate path is a planned playtest route through the same vertical slice.

## Path fields

- path id;
- completion mode;
- starting state;
- major player choice;
- expected branch outcome;
- required trace artifacts;
- expected companion presence;
- expected consequence categories;
- acceptance criteria.

## Required path set

The phase is incomplete if any of the five required paths is missing.
