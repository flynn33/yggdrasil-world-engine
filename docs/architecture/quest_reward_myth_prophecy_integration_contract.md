# Quest Reward Myth and Prophecy Integration Contract

Quest rewards may seed mythology or increase prophecy pressure.

## Myth effects

```text
myth_seed_candidate
myth_spread_pressure
mythic_location_status
mythic_lore_visibility
```

## Prophecy effects

```text
prophecy_pressure_update
prophecy_condition_progress
prophecy_visibility_update
prophecy_risk_update
```

## Boundaries

```text
Myth does not rewrite history without worldstate evidence.
Prophecy is not a guaranteed scripted future.
```
