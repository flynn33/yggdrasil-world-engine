# Ravenfall Gate Acceptance Trace Contract

Ravenfall Gate is the first vertical-slice proof location for Where Ravens Wait: Eternal Reckoning.

## Required paths

- Reveal the Buried Oath.
- Conceal the Buried Oath.
- Bind the Buried Oath.
- Study the Buried Oath.
- Weaponize the Buried Oath.

## Path requirements

Each path must prove:

- player choice is meaningful;
- branch outcome is recorded;
- consequence is routed through the Quest Reward Resolver;
- location state or branch overlay is affected or no-op justified;
- wolves are present as companions;
- ability/combat interaction is represented where applicable;
- future generation has a bias update or no-op justification.
