# Ability State Progression Contract

## States

```text
latent: potential exists but is not active.
pressured: consequence history is pushing toward manifestation.
eligible: conditions allow unlock or reveal.
unlocked: ability can be used.
unstable: ability can be used but carries coherence or consequence risk.
coherent: ability is stable in the current branch/context.
mastered: ability is integrated into the player pattern.
transformed: ability changed because branch, myth, prophecy, lineage, wolf, or plane context changed.
decohered: temporarily unavailable due to coherence loss.
sealed: blocked by oath, branch, worldstate, artifact, prophecy, or threshold condition.
```

## Rules

- `decohered` is recoverable.
- `sealed` requires explicit unseal conditions.
- Mastery does not erase consequence.
- Transformation must preserve source provenance.
