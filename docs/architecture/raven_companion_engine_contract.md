# Raven Companion Engine Contract

## Purpose

The Raven Companion Engine governs the persistent player-bound Raven Companion state.

## Runtime Invariant

```text
Every active player runtime state has a persistent Raven Companion slot.
```

For Nathruun's first campaign:

```text
raven_companion_state.companion_id = floki_hrafen_vilgerson
```

## Responsibilities

The Raven Companion Engine owns:

```text
raven companion identity
persistent presence rule
presentation absence rule
quest signal routing
threshold recognition hints
ancestral or origin resonance signals
lore recovery signals
player identity reflection
raven state contribution to reward consequences
```

## Does Not Own

The Raven Companion Engine does not own:

```text
ASH Model cosmology
ASH Pattern System canonical math
wolf manifestation rules
combat resolution
platform rendering or animation
pet inventory systems
custom-origin resolver internals
```

## State Requirements

A Raven Companion state must include:

```text
companion_id
display_name
presence_rule
runtime_status
bound_player_identity
identity_layers
primary_functions
absence_rule
source_refs
```

## Absence Rule

The Raven may be offscreen or noninteractive for presentation, but remains in runtime state. A true absence must be explicit and consequence-bearing.

## First Campaign Binding

Floki is bound to Nathruun in the canonical first campaign. Future custom-origin raven identity resolution is deferred to the custom-origin design phase.
