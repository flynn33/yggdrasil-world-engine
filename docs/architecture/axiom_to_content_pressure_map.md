# Axiom to Content Pressure Map

## Purpose

Map A1-A6 into quest, NPC, and lore generation pressures.

| Axiom | Quest Pressure | NPC Role Pressure | Lore Pressure |
|---|---|---|---|
| A1 Relational Existence | reconnect/sever/name/witness | witness, relation restorer, exile | records of severed bonds, hidden names, forgotten oaths |
| A2 Structural Compressibility | decode/stabilize/compress | interpreter, pattern keeper | inscriptions, formulae, lore archive fragments |
| A3 Multi-Scale Persistence | preserve/anchor/transmit | ancestor echo, memory carrier | lineage records, reincarnation echoes |
| A4 Energetic Cost of Erasure | contain/pay/transform | boundary keeper, cost bearer | erasure testimonies, debt records |
| A5 Self-Reference | mirror/restore/integrate | self-reference mirror, guide | journals, confessions, self-model fragments |
| A6 Branching Choice Realization | choose/reconcile/converge | branch survivor, alternate witness | branch records, divergent testimonies |

## Rule

Content may combine multiple axiom pressures, but it must identify primary and secondary drivers.
