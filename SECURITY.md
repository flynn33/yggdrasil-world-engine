# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in the Yggdrasil World Engine, please report it responsibly.

**Do not open a public issue.** Instead, contact the project maintainer directly via GitHub.

## Scope

This project is a specification repository containing JSON schemas, documentation, and validation scripts. Security concerns may include:

- Vulnerabilities in validation scripts
- Injection risks in schema processing
- Supply chain concerns in CI/CD workflows

## Response

The maintainer will acknowledge receipt within 48 hours and provide an estimated timeline for resolution.
