# Realm Data

Contains canonical realm-law artifacts that govern how realm behavior manifests
without introducing engine-specific implementation details.

## Realm Mechanics Rules

See `realm_mechanics_rules.yaml` for canonical rules covering:

- realm types
- boundary conditions
- attunement gates
- manifestation permissions and restrictions
- cross-realm bleed behavior
- stability, volatility, and resonance behavior
- transition and travel conditions
- integration boundaries with myth, prophecy, perception, and faction topology
- hard truth-boundary invariants
