# Bloodline Registry

Contains bloodline schemas and registry definitions.

## Bloodline Schema

See `bloodline_schema.json` for the base schema.

Bloodlines represent ancestral resonance with mythic structures. They affect quest interpretation, prophecy activation, myth formation, access to visions, and mythic entity response.

## Fields

- `bloodline_id` -- Unique identifier for the bloodline (e.g., "ravenson")
- `mythic_origin` -- The mythic origin of the bloodline (e.g., "odin_lineage")
- `resonance_effects` -- Array of effects this bloodline grants (e.g., "raven_symbols", "gate_patterns", "shadow_knowledge")

## Rules

Bloodlines do not lock destiny. They influence cosmic eligibility.
