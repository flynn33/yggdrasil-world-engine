# Perception Data

Contains canonical perception-layer data artifacts.

## Perception Overlay Rules

See `perception_overlay_rules.yaml` for the canonical rules governing how player-specific overlays interpret shared world anchors without rewriting canonical truth.

## Core Boundary Rules

- Perception overlays do not rewrite canonical world truth.
- Perception remains distinct from myth, prophecy, faction topology, and worldstate.
- Overlay visibility must be gate-justified and multiplayer-reconcilable.
