# Myth Archetypes

Contains myth record schemas and archetype definitions for the Myth Engine.

## Myth Record Schema

See `myth_schema.json` for the base schema.

Myth records represent generated mythology derived from significant narrative events.

## Fields

- `myth_id` -- Unique identifier for the myth
- `source_event` -- The narrative event that generated this myth
- `title` -- The title of the myth (e.g., "The Shattering of Ravenfall")
- `faction_versions` -- Different faction interpretations of the same myth
