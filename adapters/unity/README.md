# Unity Adapter

Adapter for integrating the Yggdrasil World Engine with Unity.

## Purpose

Translates YWE systems into Unity-specific implementations using native Unity APIs, C#, and Unity idioms.

## Status

Planned.

This is a platform-neutral planning surface. Concrete Unity implementation
belongs in a separately authorized downstream repository after M10 acceptance.

## Files

- `adapter_interface.md` -- Interface specification for the Unity adapter
- `environment_bridge.md` -- Environment generation hooks
- `entity_spawn_bridge.md` -- Entity spawning bridge specification
