# Unreal Adapter

Adapter for integrating the Yggdrasil World Engine with Unreal Engine.

## Purpose

Translates YWE systems into Unreal-specific implementations using native C++, Blueprints, and Unreal APIs.

## Status

Planned.

This is a platform-neutral planning surface. Concrete Unreal implementation
belongs in a separately authorized downstream repository after M10 acceptance.

## Files

- `adapter_interface.md` -- Interface specification for the Unreal adapter
- `environment_bridge.md` -- Environment generation hooks
- `entity_spawn_bridge.md` -- Entity spawning bridge specification
