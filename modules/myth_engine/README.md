# Myth Engine

The Myth Engine transforms significant events into mythology that persists in the world.

## Purpose

When significant events occur (artifact destruction, major quest completion, cosmic imbalances), the Myth Engine generates myths that influence the world going forward.

## Example

Event: `artifact destroyed`
Generated myth: `The Shattering of Ravenfall`

## Myth Influence

Myths influence:
- Books and songs in the world
- Cult beliefs
- Shrine inscriptions
- Future quests
- World rumors

Different factions can produce different versions of the same myth.

## Dependencies

- ASH Pattern Engine (pattern context)
- Narrative Engine (myth-eligible events)
