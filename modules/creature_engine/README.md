# Creature Engine

The Creature Engine generates creatures from cosmic patterns.

## Purpose

Creatures are generated from ASH pattern detection and are influenced by realm context, cosmic state, and narrative conditions.

## Dependencies

- ASH Pattern Engine (creature generation seeds)
- Realm Engine (realm-specific creature properties)
- Cosmology Engine (cosmic state influence)

## Files

- `module_description.md` -- Detailed module specification
- `creature_engine_interface.json` -- Interface definition for implementations
