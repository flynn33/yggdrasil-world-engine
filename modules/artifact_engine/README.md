# Artifact Engine

The Artifact Engine generates artifacts from cosmic patterns.

## Purpose

Artifacts are generated from ASH pattern detection and carry cosmic significance. They may be quest rewards, discovery objects, or catalysts for myth formation.

## Dependencies

- ASH Pattern Engine (artifact generation seeds)
- Realm Engine (realm-specific artifact properties)
- Narrative Engine (artifact narrative context)

## Files

- `module_description.md` -- Detailed module specification
- `artifact_engine_interface.json` -- Interface definition for implementations
