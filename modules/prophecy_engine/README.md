# Prophecy Engine

The Prophecy Engine generates future narrative attractors that influence the probability of cosmic patterns emerging.

## Purpose

Prophecies are not fixed scripts. They are probability weights that make related patterns more likely to emerge later. The Prophecy Engine manages prophecy generation, tracking, and activation.

## Prophecy Influences

Prophecies should be influenced by:
- Bloodline resonance
- High realm attunement
- Repeated myth participation
- Major cosmic imbalances

## Dependencies

- ASH Pattern Engine (pattern probability adjustment)
- Narrative Engine (prophecy trigger events)
- Realm Engine (attunement thresholds)
