# Companion Engine

The Companion Engine is an agnostic YWE feature module for companion presence and companion state routing.

## Initial Scope

```text
persistent Raven Companion state
conditional White Wolf / Dark Wolf manifestation events
companion contribution to quest reward consequence routing
```

## Canon

```text
Raven = constant witness / persistent companion.
Wolves = conditional threshold presences.
```

## Non-Goals

```text
platform animation
pathfinding
combat AI behavior trees
pet inventory implementation
summon UI
morality meters
```
